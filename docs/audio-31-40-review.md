## 발견 및 수정

- 누락된 35개 항목 복원: 단어 3개, 문형 7개, 회화 25개.
- 33·34과의 문형 제목 8개를 예문 목록에서 제외. 실제 문형 예문은 각 24개.
- 기존 22개 항목의 잘린 단어, 두 열이 섞인 뜻, 숫자 주석, 한국어 줄바꿈 조각 수정.
- 이름 읽기는 PDF 번역란의 가나 표기를 근거로 복원. 사전에서 이름을 추정하지 않음.
- 기존 정상 항목 ID는 유지. 잘못 저장된 문제 문구를 새 음성과 재사용하지 않도록 세션 유효성 검사 추가. 별도로 저장되는 헷갈림·복습 기록은 삭제하지 않음.
- 회화의 문장 사이 쉼을 제거하지 않고 한 발화 전체를 보존. 40과의 감사 인사 → 잠깐만요 → 승강장 질문도 하나의 전체 발화로 연결.
- ASR가 다음 대사의 첫 단어를 이전 대사의 끝부터 표시하는 오류를 실제 무음 경계와 대조하여 수정.
- 33과의 짧은 부정 대답 2개와 39과의 `ううん、渡した。`는 더 명확하게 인식되는 원본 첫 번째 반복을 사용.

## 검증 방법과 결과

1. PDF의 일본어·한국어 쌍과 항목 순서 대조. 회화 누락 및 페이지를 넘어간 문형 예문 복원.
2. 단어·문형은 교재 항목 수와 음성 그룹 수를 일치시킨 뒤 생성. 개수가 다르면 즉시 중단하도록 보호 장치 추가.
3. 최종 음성 조각 434개를 정답 텍스트 힌트 없이 로컬 음성 인식으로 재검사.
4. 전체 문구가 정확히 일치하지 않은 44개는 개별 조각으로 추가 재인식. 짧은 부정 대답 3개는 다른 반복을 선택하고 개별 재인식 결과가 정확히 일치함을 확인.
5. 434개 MP3 전체 디코딩 오류 없음. 개발 서버에서 전체 파일의 HTTP 응답과 audio/mpeg 형식 확인.
6. 1–30과의 기존 음성 메타데이터 및 범위 밖 문제 데이터가 바뀌지 않았음을 비교 확인.
7. 단위 테스트 40개 및 프로덕션 빌드 통과. 독립 Chromium UI 테스트는 실행 환경의 권한 제한으로 시작되지 않아 앱 내 브라우저에서 31과 문장 정답·듣기와 40과 `표 → きっぷ → 切符` 직접 입력·듣기 동작을 별도 확인. 두 화면에서 콘솔 오류 없음.
8. 개별 전사 결과와 최종 434개 파일의 SHA-256 및 매칭 정보는 로컬 `work/audio-31-40-review/`에 보관.

### 음성 인식의 한계

자동 전사 점수는 정확성의 보증이 아님. `夕べ/昨夜`, `着ません/来ません`, `うち/家`, 한국인 이름, `あのう/あのー` 등은 같은 음성도 다른 표기로 전사될 수 있어 점수만으로 잘못된 음성으로 판단하지 않았다. 출판사 원음의 해당 발화 순서와 구간, PDF 표기를 함께 대조했다. `じゃ/じゃあ`, `すみません/すいません` 같은 원음의 자연스러운 발화 차이는 음성을 합성·변조하지 않고 유지했다. 전 항목을 사람이 직접 청취한 검수라는 의미는 아니다.
