# 일본어 복습 테스트

개인 학습용 PDF에서 개발 단계에 추출한 1~60과 데이터를 사용하는 일본어 복습 웹앱입니다.

## 실행

```bash
npm install
npm run dev
```

검증 명령:

```bash
npm run test
npm run build
```

## 현재 범위

- 과 다중 선택 (1~60과)
- 10 · 20 · 30 · 전체 문제 선택
- 전체 · 단어 · 문장(문형과 회화) 유형 선택
- `빠른 복습`: 5지선다, 일본어 → 한국어 / 한국어 → 일본어 혼합
- `직접 입력`: 기본 단어, 한국어 → 일본어
- 한자 단어는 한자와 저장된 히라가나 독음을 모두 정답으로 인정
- 문제와 선택지 중복 방지
- 같은 과·비슷한 문장 구조를 우선한 오답 선택지
- 선택 즉시 정답·오답 표시, 답안 잠금
- 이전·다음 이동, 상단 진행률 표시 및 새로고침 복원
- 결과별 답안 확인, 같은 과 다시 풀기
- 오답과 복습 시점이 된 문제를 다음 테스트에서 우선 출제

학습 기록은 브라우저에만 저장합니다. PDF, OCR, AI API, Supabase는 실행 중 사용하지 않으며 원본 PDF도 배포 파일에 포함하지 않습니다.

## 데이터 다시 추출하기

`scripts/extract_pdf.py`는 텍스트 선택이 가능한 원본 PDF를 읽어 `src/data/question-bank.json`을 다시 생성합니다. `pdfplumber`가 설치된 Python 환경이 필요합니다.

```bash
python3 scripts/extract_pdf.py /path/to/source.pdf src/data/question-bank.json
```

교재 데이터는 개인 학습 범위에서만 사용하고 배포 주소는 공유하지 않는 것을 권장합니다.
